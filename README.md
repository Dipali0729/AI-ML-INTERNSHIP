# 🚢 Titanic Data Cleaning & Preprocessing

## 📌 Objective
To clean and preprocess raw data for Machine Learning using the Titanic dataset.

## 🛠 Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## 🔍 Steps Performed
- Explored dataset (checked null values & data types)
- Handled missing values (Age → median, Embarked → mode, dropped Cabin)
- Encoded categorical variables (Label Encoding & One-Hot Encoding)
- Detected and removed outliers using IQR
- Applied feature scaling using StandardScaler
- Split data into training and testing sets

## 🎯 Outcome
Prepared a clean and structured dataset ready for Machine Learning model training.
