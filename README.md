#Task 1
# 🚢 Titanic Data Cleaning & Preprocessing

## 📌 Objective
To clean and preprocess raw data for Machine Learning using the Titanic dataset.

## 🛠 Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## 🔍 Steps Performed
- Explored dataset (checked null values & data types)
- Handled missing values (Age → median, Embarked → mode, dropped Cabin)
- Encoded categorical variables (Label Encoding & One-Hot Encoding)
- Detected and removed outliers using IQR
- Applied feature scaling using StandardScaler
- Split data into training and testing sets

## 🎯 Outcome
Prepared a clean and structured dataset ready for Machine Learning model training.

#Task 2 
# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)

## Objective
Perform EDA to understand patterns, trends, and relationships in the Titanic dataset using statistics and visualizations.

## Tools
Python | Pandas | NumPy | Matplotlib | Seaborn | Plotly

## Steps
- Data inspection & missing value check  
- Summary statistics: mean, median, std  
- Visualizations: histograms, boxplots, count plots, correlation heatmap, pairplots  
- Detected skewness, outliers, and feature relationships

## Key Insights
- Females had higher survival than males  
- 1st class passengers survived more  
- Fare positively correlated with survival  
- Missing values in Age & Cabin, outliers in Fare
